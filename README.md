# 🔀 PA — Tomada de Decisão

Repositório de exercícios de Programação e Algoritmos focados em estruturas condicionais, usadas para executar ações diferentes de acordo com condições definidas.

## 📖 Sobre o projeto

O projeto reúne atividades práticas para exercitar a lógica de tomada de decisão. Os exercícios estão separados em diretórios que organizam listas e exemplos de estruturas condicionais.

## ✨ Conteúdo

- 🧠 Prática de lógica condicional.
- 🔀 Exercícios de decisões simples e encadeadas.
- 📚 Listas e projetos de treino organizados em pastas.

## 🛠️ Tecnologias utilizadas

- **Programação:** linguagem conforme os arquivos de cada atividade.

## 📂 Estrutura do projeto

```text
PA-TomadaDecisao/
├── TomadaDecisaoEncadeada/
├── TomadaDecisaoLista2/
├── TomadaDecisaoTreino/
├── prjTomadaDecisao/
└── README.md
```

## 🚀 Como executar os exercícios

1. Clone o repositório:
   ```bash
   git clone https://github.com/yhaguihara/PA-TomadaDecisao.git
   ```
2. Entre na pasta:
   ```bash
   cd PA-TomadaDecisao
   ```
3. Abra os arquivos em uma IDE ou editor compatível com a linguagem utilizada.

## 🎯 Objetivo de aprendizagem

Praticar estruturas condicionais e aprimorar o raciocínio lógico na resolução de problemas.
